## Како Hugo ги користи

Hugo автоматски детектира кога корисникот бара:
- „Направи слика на...“ → higgsfield_image
- „Направи видео...“ → higgsfield_video
- „Направи бренд за...“ → higgsfield_brand
- „Направи кампања за...“ → higgsfield_campaign

## API Key

Корисникот треба да го внесе својот API key од https://cloud.higgsfield.ai
во Hugo Settings → Higgsfield API Key.

Без API key, овие tools не работат.
